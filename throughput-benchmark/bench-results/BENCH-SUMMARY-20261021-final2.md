## Caveats

- One run per suite: differences of a few percent are within run-to-run noise.
- Both writers ran side by side on the same nodepool and bucket, so each rate is under the same shared load.
- Paimon's Iceberg export is on (`ICEBERG_COMPAT=true`): every Paimon commit also writes Iceberg metadata, work the Iceberg writer does not do.
- The snapshot test ran on compacted tables (section above), the hot test on uncompacted ones; snapshot numbers are not comparable with sessions that did not compact.
- Query times compare engines on equal CPU and memory (StarRocks 3 BEs × 9 cpu / 38 Gi vs DuckDB 27 cpu / 114 Gi; memory limit 90% of the pod and cache memory 20% of it, on both), with both caches emptied before each test.
